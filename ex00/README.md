# Portfolio Website (ex00)

Authentic responsive personal portfolio built from scratch without external frameworks or UI component libraries.

## Features
- **Semantic HTML5 & Modern CSS3**: Structured layout leveraging CSS Grid and Flexbox.
- **Dynamic Theme Switcher**: Interactive light/dark mode persistence via JavaScript and CSS custom properties.
- **Fully Responsive**: Fluid layout adapted seamlessly for mobile, tablet, and desktop screens.
- **Project Showcase**: Highlights Projects 00 through 03 with clean tech tags and live mock links.
- **Client-side Form Validation**: Robust input verification for visitor inquiries.

## Running Locally
Clone or open the repository folder and launch `index.html` in any modern web browser. No compilation or server installation required.
